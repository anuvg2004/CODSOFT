\# CODSOFT Python Internship Tasks



This repository contains the tasks completed as part of the CODSOFT Python Programming Internship.



\## Completed Tasks



\### 1️⃣ Smart Calculator

A flexible calculator built using Python.



Features:

\- Performs Addition, Subtraction, Multiplication, Division

\- Supports multiple operations

\- Chain mode and Normal mode

\- Handles division by zero

\- User-friendly interface



\### 2️⃣ Password Generator

A secure password generator built using Python.



Features:

\- User-defined password length

\- Includes uppercase and lowercase letters

\- Includes numbers and special characters

\- Ensures at least one letter, number, and symbol

\- Shuffles characters for better security
