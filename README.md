\## ✅ Completed Tasks



\### 1️⃣ Smart Calculator

A flexible calculator built using Python.



\*\*Features:\*\*

\- Performs Addition, Subtraction, Multiplication, Division

\- Supports multiple operations at once

\- Chain Mode (uses updated result)

\- Normal Mode (uses original numbers)

\- Handles division by zero

\- Continuous execution until user exits



Run using:

```bash

python calculator.py

```



---



\### 2️⃣ Advanced Password Generator

A secure password generator built using Python.



\*\*Features:\*\*

\- User-defined password length

\- Includes uppercase and lowercase letters

\- Includes numbers and symbols

\- Ensures at least one letter, number, and symbol

\- Shuffles password for better security



Run using:

```bash

python password\_generator.py

```
